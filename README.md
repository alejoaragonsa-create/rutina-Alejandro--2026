# Rutina 2026 — Web App (Streamlit)

## 1) Requisitos
- Python 3.10+ instalado

## 2) Instalar dependencias
```bash
pip install -r requirements.txt
```

## 3) Ejecutar
Dentro de esta carpeta:
```bash
streamlit run app.py
```

Se abrirá en tu navegador.  
Los datos se guardan en `data/<perfil>.json`.

## 4) Subirla online (opcional)
1. Crea un repositorio en GitHub y sube `app.py` y `requirements.txt`
2. En Streamlit Community Cloud, elige el repo y despliega.
